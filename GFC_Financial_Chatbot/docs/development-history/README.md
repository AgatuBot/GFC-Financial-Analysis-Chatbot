# Development History

This directory preserves application checkpoints created during the development of the GFC Financial Analysis Chatbot.

The historical files are retained as development evidence. The production/current application is pp.py in the parent directory.

## Historical Checkpoints

- pp_before_security_upgrade.py — checkpoint before the security-related changes.
- pp_after_security_upgrade.py — checkpoint after the security-related changes.
- pp_before_multi_company_logic.py — checkpoint before multi-company logic work.
- pp_after_multi_company_upgrade.py — checkpoint after multi-company functionality was added.
- pp_before_multi_company_upgrade.py — checkpoint before a subsequent multi-company upgrade.
- pp_before_function_move.py — checkpoint before function-organization changes.
- pp_before_encoding_fix.py — checkpoint before encoding-related corrections.
- pp_before_comparison_upgrade.py — checkpoint before comparison functionality was upgraded.
- pp_after_comparison_upgrade.py — checkpoint after comparison functionality was upgraded.
- pp_after_logic_tests.py — checkpoint following logic testing.

These files are historical development artifacts and are not used directly when running the current application.
